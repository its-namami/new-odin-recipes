# Odin Recipes

A small recipe website I built for The Odin Project's Foundations course.

It has an index page that links to three recipes: lasagna, cereal, and air sandwich. Each recipe page has an image, a description, an ingredients list, and cooking steps.

View the live site: [its-namami.github.io/new-odin-recipes](https://its-namami.github.io/new-odin-recipes/)
